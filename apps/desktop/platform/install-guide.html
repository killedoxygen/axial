What happens after you downloadHere’s exactly what you’ll see

Drag Axial into Applications

Open the file you downloaded. In the window that appears, drag Axial onto the Applications folder.

Open Axial. macOS stops it the first time

Open Axial from your Applications folder. macOS shows this message because Axial isn’t registered with Apple. Click Done, not Move to Trash.

Haven’t copied it yet? First drag Axial onto Applications in the window behind this one.

Open Privacy & Security

This button takes you straight to the right page in System Settings.

Open Privacy & Security

Your browser asks first. Choose Allow.

Nothing opened? Open System Settings yourself and choose Privacy & Security.

Scroll down and click Open Anyway

Near the bottom, under Security, Axial is listed as blocked. Click Open Anyway, then confirm with Touch ID or your Mac’s password.

Click Open Anyway once more

That’s it. Axial opens, keeps itself up to date, and macOS won’t ask again.

Keep the download

Your browser may say the installer isn’t commonly downloaded. In Edge, click ⋯ next to it, then Keep. Chrome just shows Keep.

If Edge asks again, click Show more, then Keep anyway.

Tell Windows to run it

Open the installer. Windows may show a blue warning because Axial isn’t signed with a paid certificate. Click More info, then Run anyway.

Click through the installer

Click Next, then Install. Axial opens when it’s done and keeps itself up to date from then on.

Allow it to run

Right-click the AppImage you downloaded and choose Properties. Turn on Executable as Program, which some systems call “Allow executing file as program”.

Double-click the AppImage

Axial starts and keeps itself up to date from then on.

Nothing happens on Ubuntu 22.04 or newer? Install FUSE once with sudo apt install libfuse2t64 (on 22.04: libfuse2), then try again.

Why the warnings? Axial is free, and the certificates that silence them cost money every year. Every update is still signed by Axial and checked before it installs.
